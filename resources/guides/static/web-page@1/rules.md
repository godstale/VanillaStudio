# Rules: static page scene

> Skeleton. Full rules are written in V3 (T3.5/T3.7/T3.9).

## Core

Build a page that advances only on user input (click, key, or choice). No timers or auto-advance.

## Rules

- Follow `mode`: `scroll` is one long page, `steps` is a slide-like sequence from `steps[]`.
- Use semantic HTML, a readable type scale, and keyboard access.
- Layout must hold at the breakpoints listed in `breakpoints`.
