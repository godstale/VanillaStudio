# 바닐라 스튜디오(Vanilla Studio) 구현 요구사항

## 바닐라 스튜디오란?

바닐라 스튜디오는 파워포인트 또는 웹 사이트, 동영상, 애니메이션 등을 심미적으로 띄어난 형태로 디자인하기 위한 도구입니다. 
특히 클로드 코드, Codex, AGY, Hermes, OpenCode 와 같은 에이전트를 도구로 사용해서 정적인 웹 페이지, 2D/3D 영상, PPT 페이지 등을 만들어 내는것을 목표로 합니다.
기존에는 이런 창작 과정이 adobe, powerpoint 와 같은 도구들이 정해놓은 규칙과 프로토콜 안에서 동작합니다. 하지만 바닐라 스튜디오는 결과물을 보여줄 수 있는 출력 플랫폼인 브라우저와 HTML/JS/CSS 등과 같은 최소한의 제약만을 설정하고, 에이전트가 자율적으로 창의적인 작업들을 수행하는 것을 지향합니다. 이 과정에서 이미지/동영상 생성을 위한 힉스필드, VEO, 나노바나나 같은 생성형 AI 서비스를 배제하고 에이전트가 코딩을 이용해 구성요소들을 하나씩 쌓아올리는 방식을 사용합니다.
이렇게 기존의 레거시 구조와 관념을 버리고 에이전트 본연의 능력을 최대한 발휘하는 디자인 스튜디오로 만들기 위해 "바닐라" 스튜디오라 이름지었습니다.

## 바닐라 스튜디오의 동작 구조
1. 사용자는 최종 결과물의 형태를 지정한다. (ex: 웹 페이지, PPT, 스틸샷, 동영상, 캠페인 이미지 등)
2. 사용자는 결과물의 화면(Scene)을 구성하는데 필요한 배경 지식이나 자료를 제공한다.
3. 에이전트를 이용해 사용자가 원하는 결과물을 만들기 위한 기획서를 작성한다. 기획서는 결과물을 만들기 위해 필요한 화면, 화면 내에서의 asset 배치, asset 움직임, 애니메이션 타임라인 등의 정보를 포함한다. 또한 각 화면과 Asset, 애니메이션 등을 작성하기 위한 최적의 구현 방법과 구현 단계에서 사용자가 customize 가능한 범위를 미리 제시해야 한다.
4. 사용자가 기획서를 확인하면 화면(Scene), Asset, 애니메이션 등을 만들기 위한 프롬프트를 작성한다. 이 프롬프트는 구현 계획서에 해당하며, 에이전트가 최적의 결과물을 만들기 위해 필요한 상세한 내용들을 담고 있다. 또한 화면을 구성하는 개별 asset 부터 작성해서 최종적으로 화면이 완성될 수 있도록 구현 순서를 전체 구현 계획서에 포함해야 한다. asset, 애니메이션과 같이 화면(scene)의 하위 항목들은 개별 구현 계획서(프롬프트)를 작성한다. 
5. 구현 계획서(프롬프트)를 이용해 화면을 작성한다. (결과물의 종류에 따라 단일 화면이 될 수도 있고, 여러 화면의 조합이 될 수도 있다.)
6. 검수 메뉴에서 작성된 화면을 사용자가 확인한다.
6-1. 각 화면과 애셋, 애니메이션 등은 사용자가 수동으로 조절해 볼 수 있다.
6-2. 만약 화면이나 애셋, 애니메이션을 변경하고 싶은 경우 현재 결과물과 함께 구현 계획서(프롬프트)를 수정해서 에이전트에게 요청한다.
6-3. 수정된 결과물을 검수 화면에서 반복적으로 확인하고 테스트 한다.
7. 최종 결과물 형태로 export 한다.

## 최종 결과물
바닐라 스튜디오는 에이전트를 이용해 심미적으로 뛰어난 결과물을 손쉽게 만들 수 있도록 해주는 것이 목표이다.
- 최종 결과물은 웹 페이지, PPT, 이미지, 2D/3D 동영상, 2D/3D 인터랙티브 페이지
  - 2D/3D 인터랙티브 페이지: 사용자 input에 따라 카메라/Asset 이 반응하는 페이지
- 검수용 중간 결과물, 최종 결과물은 React + three.js 기반의 앱에서 사용할 수 있는 패키지 형태를 지향하지만, 다른 범용적이고 좋은 대안이 있다면 해당 방식을 따르고자 한다.
- 최종 결과물은 PPT, 이미지/동영상 포맷 형태일 수도 있고 web 에서 사용 가능한 코드와 리소스의 패키지일 수도 있다.

## 디자인 템플릿
에이전트가 사용자가 원하는 형태의 디자인을 창조할 수 있도록 템플릿을 제공한다.
템플릿은 화면(Scene), Asset, 애니메이션, 동영상 등을 다양한 디자인으로 미리 만들어 둔 구현 계획서(프롬프트)의 패키지이다.
사용자는 원하는 디자인의 템플릿을 지정함으로써 결과물을 원하는 스타일로 작성되도록 유도할 수 있다. 

## 플레이 그라운드
사용자가 만든 최종 결과물을 보관하고 재생해 볼 수 있는 메뉴이다.
추후에는 바닐라 스튜디오 서버와 연결해서 다른 사람의 공개 작품들을 조회해 볼 수 있도록 기능을 확장할 것이다.
