# AGENTS.md 골격 — 에이전트 주도 앱 개발용

> 새 프로젝트의 AGENTS.md를 만들 때 아래 절을 순서대로 채운다. Vanilla Studio의 `AGENTS.md`가 완성 예시다.

1. **시작 전 반드시 읽을 것** — 문서 지도(요구사항·기획·설계·결정·플레이북·wiki index)
2. **프로젝트 개요** — 한 줄 정의, 현재 단계(P0~P7)
3. **기술 스택(고정)** — 패키지 매니저, 프레임워크, 금지 라이브러리
4. **코딩 컨벤션** — 타입, 문구(i18n), 색 토큰, 주석 원칙, 범위 준수
5. **도메인 규칙** — 앱 고유의 계약·보안 경계(예: Scene 런타임 계약, 에이전트 권한 정책)
6. **빌드/검증 명령** — 완료 조건
7. **Git 규칙** — 브랜치, 커밋, push 승인
8. **안전/보안 원칙**
9. **Wiki 지식베이스 규칙** — 언제·어디에·어떻게 기록하는가
10. **단계(Phase) 운영과 플레이북 규칙** — 단계별 산출물, 단계 종료 시 기록 의무
