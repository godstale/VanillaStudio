# 시퀀스와 플레이그라운드 (Sequence & Playground)

시퀀스는 신들을 **선으로 이은 흐름**입니다. 워크스페이스마다 시퀀스는 하나이며(`sequence.json`), PPT처럼 클릭으로 넘기거나, 영상처럼 자동으로 이어지거나, 선택지로 갈라지게 만들 수 있습니다.

## 1. 신 잇기

- 노드 오른쪽 핸들에서 다른 노드로 끌어 선을 만듭니다. 같은 두 신 사이에는 선을 하나만 만들 수 있습니다.
- 선을 고르면 오른쪽에 **연결 설정**이 열립니다. 삭제는 설정의 휴지통 버튼 또는 `Delete` 키입니다.
- 선 끝을 다른 노드로 끌면 도착(또는 출발) 신이 바뀝니다.
- 노드를 고른 뒤 인스펙터 **개요**의 **시작 신으로 지정**을 누르면 재생이 거기서 시작합니다(노드에 **시작** 배지가 붙습니다).
- 캔버스 왼쪽 위 선택 상자에서 **모드**를 고릅니다: *선형*(슬라이드·영상: 신마다 나가는 선 1개, 선택지 없음) / *인터랙티브*(분기 가능).

## 2. 넘어가는 조건 (trigger)

| 조건 | 언제 다음 신으로 가나 | 비고 |
| --- | --- | --- |
| 신이 끝나면(`end`) | 모션·3D가 끝 시각에 도달 | 정적 페이지에는 쓸 수 없음 |
| 일정 시간 뒤(`timeout:3s`) | 신이 재생을 시작한 지 N초 뒤 | 일시정지하면 타이머도 멈춤. 정적 페이지에는 쓸 수 없음 |
| 클릭하면(`click`) | 클릭 | 정적 페이지는 마지막 단계에서만 |
| 키를 누르면(`key:ArrowRight`) | 그 키 | |
| 선택지(`choice:이름`) | 화면의 선택지 버튼을 고르면 | 인터랙티브 모드. 같은 신에서 나가는 선마다 이름이 달라야 함 |

**정적 페이지는 시간으로 넘어가지 않습니다.** 사용자 입력(클릭·키·선택지)만 가능하며, 설정 화면에서 자동 조건은 고를 수 없습니다.
처음 만든 선은 신 타입에 맞는 기본값(정적=클릭, 그 밖=끝나면)이 들어가고, 같은 신에서 두 번째로 나가는 선은 도착 신 이름의 선택지가 됩니다.

## 3. 전환 (transition)

연결 설정에서 종류·길이(ms)·이징을 고릅니다.

- 내장: **컷**, **크로스페이드**, **슬라이드**(왼쪽·오른쪽·위·아래), **마스크 와이프**(방향), **원형 공개**(중심), **줌 통과**(배율)
- **사용자 정의**: 워크스페이스 `transitions/<이름>.json`에 선언형 키프레임을 두면 목록에 나타납니다(코드가 아니라 데이터입니다). 에이전트에게 요청하면 `AGENTS.md`의 규칙대로 만들어 줍니다. 허용 속성은 `opacity`·`transform`·`clipPath`·`filter`입니다.
- 매치 컷(요소를 맞춰 잇기)은 지원하지 않습니다.

## 4. 시퀀스 검사

규칙을 어기면 캔버스 오른쪽 아래에 목록이 뜨고, 오류가 있으면 플레이그라운드가 재생하지 않습니다.

- 오류: 없는 신, 정적 페이지의 자동 조건, 같은 신의 같은 조건 두 개, **입력 없이 영원히 도는 순환**, 선형 모드의 분기·선택지, 시작 신 없음, 알 수 없는 전환
- 경고: 시작 신에서 갈 수 없는 신
- 입력(클릭·키·선택지)이 한 번이라도 필요한 순환은 허용됩니다(예: 마지막에서 처음으로 돌아가는 선택지).

## 5. 플레이그라운드

사이드바의 **플레이그라운드**에서 시퀀스를 처음부터 재생합니다.

- 아래 막대: 처음부터·재생/일시정지·시크 막대·현재 시각(모션·3D), 이전/다음 단계와 단계 표시(정적), 신 번호 버튼(그 신으로 바로 이동, 전환 없음).
- 화면을 **클릭**하거나 화살표 등 **키**를 누르면 그 입력에 맞는 선을 따라갑니다. 정적 페이지는 먼저 단계가 넘어가고, 마지막 단계에서야 선을 따라갑니다.
- 선택지는 화면 아래 버튼으로 나옵니다. 현재 신 안의 버튼은 재생 중 직접 누를 수 없고 이 버튼으로 대신합니다.
- 다음 신은 미리 불러 둡니다. 불러오지 못하면 현재 신에 머물고 오류 배너와 **다시 시도**가 나옵니다.
- 끝에 도달하면 끝 화면과 **처음부터** 버튼이 나옵니다.

## 6. 샘플로 연습하기

`resources/samples/sequence-demo/`는 모션 → 정적(클릭 3단계) → 3D, 그리고 끝에서 *Finish*(원형 공개로 마무리)·*Again*(처음으로)을 고르는 시퀀스입니다. 워크스페이스 템플릿 위에 덮어 쓰면 열립니다(`Docs/Verification/Golden-Samples.md`).
