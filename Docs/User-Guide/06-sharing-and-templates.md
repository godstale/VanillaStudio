# 공유와 템플릿 (Sharing & Templates)

## 1. 패키지(.vsx)로 공유하기

패키지는 신(또는 시퀀스 전체)을 **파일 하나**로 묶은 것입니다. 받는 사람은 자기 워크스페이스에서 엽니다.

**내보내기**: 캔버스 왼쪽 위 **공유(.vsx)** → 범위(시퀀스 전체 / 선택한 신만)를 고르고 저장 위치를 정합니다.

- 담기는 것: `scene.json`·`GUIDE.md`·`AGENTS.md`·`DESIGN.md`·`prompts/`·`src/`·`params/`·`references/references.json`·분석 결과, 시퀀스 전체라면 `workspace.json`·`sequence.json`·`transitions/`, 쓰는 **사용자 정의 템플릿**.
- 안 담기는 것: `.vanilla/`(앱 상태·썸네일·이력), `node_modules`, 숨김 파일, 그 밖의 알 수 없는 파일.
- **레퍼런스 원본 이미지·영상은 기본 제외**입니다(용량이 크고 공유할 권리가 없을 수 있음). 필요하면 "레퍼런스 원본 포함"을 켜세요. 분석 노트와 레퍼런스 목록은 항상 담깁니다.
- 워크스페이스 밖(설정의 전역 템플릿 폴더)에 있는 템플릿은 담을 수 없어 경고가 뜹니다. 받는 사람에게도 따로 필요합니다.
- 같은 내용이면 항상 같은 파일이 만들어집니다(파일 수정 시각이 달라도). 파일마다 SHA-256이 들어 있어 전송 중 손상은 열 때 발견됩니다.

**열기(가져오기)**: **패키지 열기…** → `.vsx` 선택.

1. 먼저 **검사**만 합니다. 이 단계에서 어떤 파일도 쓰지 않습니다. 안전하지 않은 경로(`..`·절대 경로)·링크(심링크)·암호화 항목·체크섬 불일치·너무 큰 파일은 거부하고 이유를 알려 줍니다.
2. 패키지 종류·원본 워크스페이스·만든 앱 버전·파일 수와 크기, 형식 호환 여부를 보여 줍니다. 더 새롭거나 다른 데이터 형식이면 열 수 없습니다.
3. **에이전트가 읽게 될 지시 파일 목록**(AGENTS.md·프롬프트·템플릿·DESIGN.md)이 나옵니다. 출처를 알고 신뢰할 때만 "신뢰합니다"를 체크하세요. 체크하기 전에는 **가져오기**를 누를 수 없습니다.
4. 가져올 신을 고르면 현재 워크스페이스에 **새 신으로 복사**됩니다(원본과 연결되지 않음). 새 신 id를 받고, 가이드 파일은 이 워크스페이스 기준으로 다시 만들어집니다. 시퀀스 패키지에서 모든 신을 가져오면 신 사이의 연결도 함께 옮겨지고, 이 워크스페이스에 시작 신이 없으면 원래 시작 신이 지정됩니다.
5. 패키지가 동봉한 템플릿은 이미 같은 이름이 있으면 **건드리지 않습니다**(덮어쓰기·병합 없음). 쓸 수 없는 템플릿을 쓰는 신은 가져오되 가이드 파일을 만들지 못했다고 알려 줍니다.

## 2. 신 템플릿으로 저장

잘 만든 신의 **구조**를 새 신의 출발점으로 쓰고 싶을 때: 신 인스펙터 **개요 → 신 템플릿으로 저장**에서 이름을 적고 저장합니다.

- 남는 것: 시간 구조(길이·beats의 구간·역할·모션·카메라·전환)·스타일·모션 어휘·엔드 카드 시간(모션·3D), 모드·steps의 뼈대·섹션·레이아웃(정적).
- 비워지는 것: 브리프·내 프롬프트·레퍼런스·카피·정체성·오디오, beats·steps의 문구·시각 설명·메모.
- 가이드 규칙·체크리스트·프롬프트는 이 신이 쓰던 템플릿을 그대로 **상속**합니다.
- 저장하면 워크스페이스 `guide-templates/<이름>@1/`에 만들어지고, **신 추가**에서 템플릿으로 고를 수 있습니다. 같은 이름이 있으면 덮어쓰지 않고 거절합니다.

사용자 템플릿을 더 고치려면 **설정 → 가이드 템플릿**에서 복제·편집합니다. 내장 스키마는 **확장만** 가능하고(필드 추가·숨김·기본값·규칙 추가), 검증에 실패한 템플릿은 목록에서 빠지고 이유가 표시됩니다.

## 3. v1 프로젝트 가져오기

시작 화면의 **v1 프로젝트 가져오기…**:

1. v1 프로젝트 폴더(`vanilla.json`이 있는 폴더)를 고르면 **미리보기**가 나옵니다: 새 신 타입(웹·슬라이드→정적, 영상·이미지→모션, 인터랙티브→선택), 화면 규격, 가져올 파일 수, 그리고 **변환하지 못했거나 일부만 변환한 항목**(보관·부분·제외 표시와 이유).
2. 새 워크스페이스를 만들 **빈 폴더**를 고르면 변환합니다. v1 폴더는 읽기만 하며 바뀌지 않습니다.
3. 가져온 것: 코드(`src/`)·조절값(`params/`)·`DESIGN.md`·브리프 핵심 필드·이미지/영상 자료(레퍼런스로 등록)·계획서의 구간(beats·단계 초안). v1의 문서 원본은 `scenes/<이름>/v1-archive/`에 보관됩니다. 검수 기록·내보내기 결과·프롬프트 폴더는 가져오지 않습니다.
4. v1 프로젝트 하나는 신 하나가 됩니다. v1의 여러 Scene은 그 신의 코드 안에 그대로 있습니다.

변환이 완벽하지 않을 수 있습니다. 재생이 어긋나면 미리보기의 "변환하지 못한 항목"과 `v1-archive/`를 확인하고, 필요하면 v1 앱(`v1-final` 태그)으로 여세요.
