# 시작하기 (Getting Started)

Vanilla Studio는 **캔버스 위에서 신(Scene)을 만들고 이어 붙여** 정적 페이지·모션 그래픽·3D 애니메이션을 만드는 데스크탑 앱입니다.
화면은 코딩 에이전트(Claude Code·Codex 등)가 **코드로** 만들고, 앱은 신마다 지침을 정리해 주고 결과를 재생·검토합니다.
생성형 이미지·영상 AI는 쓰지 않습니다.

> 이 문서는 `Docs/User-Guide/`에 있으며, 앱의 **설정 → 앱 → 사용자 문서**에서도 위치를 볼 수 있습니다.

## 1. 준비물

| 항목 | 요구 | 비고 |
| --- | --- | --- |
| OS | Windows 10/11 64비트 | 다른 OS는 공식 지원이 아닙니다 |
| Node.js | 22 이상 | 환경 점검(Doctor)이 확인합니다 |
| pnpm | Node corepack으로 켭니다 | `corepack enable pnpm` |
| 코딩 에이전트 CLI | 최소 1개 | Claude Code·Codex·OpenCode·Hermes·AGY. 설정 → 에이전트에서 켜고 끕니다 |
| FFmpeg | 영상 레퍼런스의 키프레임을 뽑을 때만 | Doctor에서 앱이 내려받을 수 있습니다(`02-doctor.md`) |

설치 상태가 의심스러우면 **설정 → 환경 점검**을 먼저 여세요.

## 2. 첫 워크스페이스 만들기

**워크스페이스 = 작업 폴더 1개 = 시퀀스 1개**입니다. 다른 시퀀스를 만들고 싶으면 새 워크스페이스를 만듭니다.

1. 앱을 처음 열면 시작 화면이 나옵니다. **작업 폴더 선택**으로 빈 폴더를 고릅니다(이미 워크스페이스인 폴더를 고르면 그대로 열립니다).
2. 이름과 **화면 규격**(16:9·9:16·1:1·사용자 지정)과 fps를 정합니다. 화면 규격은 워크스페이스 전체에 하나입니다.
3. 의존성 설치(`pnpm install`)에 동의하면 만들어집니다. 고정된 명령만 실행하며, 신뢰하지 않은 폴더에서는 에이전트와 미리보기가 시작되지 않습니다.
4. v1 프로젝트가 있다면 시작 화면의 **v1 프로젝트 가져오기…** 를 쓰세요(`06-sharing-and-templates.md`).

## 3. 화면 구성

- **왼쪽 사이드바**: 워크스페이스(캔버스)·신 목록·플레이그라운드·설정. 맨 위에서 최근 워크스페이스로 전환합니다.
- **가운데 캔버스**: 신이 노드로 보입니다. 노드를 끌어 옮기고, 오른쪽 핸들에서 다른 노드로 **선을 이어** 신 사이의 흐름(시퀀스)을 만듭니다. 빈 곳에서 오른쪽 클릭하면 신을 추가합니다.
- **오른쪽 인스펙터**: 노드를 고르면 그 신의 개요·가이드·디자인·레퍼런스·프롬프트·미리보기 탭이 열립니다. 선을 고르면 연결 설정이 열립니다.
- **아래 터미널 도크**: 에이전트가 신 폴더에서 실행되는 터미널입니다.

## 4. 한 번 돌려 보기

1. 캔버스에서 **신 추가** → 이름·타입(정적 페이지·모션 그래픽·3D)을 정합니다. 신 폴더가 `scenes/<이름>/`에 만들어지고 `scene.json`·`GUIDE.md`·`AGENTS.md`·`prompts/`가 생깁니다.
2. 인스펙터의 **개요**에서 주제·목적·대상·핵심 메시지를 적고, **가이드** 탭에서 구조·스타일을 고릅니다(`03-scenes-and-guides.md`).
3. 노드의 **에이전트 실행**을 누르면 터미널이 열리고, 프롬프트가 클립보드에 복사됩니다. 에이전트에 붙여넣으면 에이전트가 `src/`에 코드를 만듭니다.
4. 에이전트가 끝나면 앱이 변경 사항을 보여 줍니다. 확인하고 **승인**하세요.
5. **미리보기** 탭이나 노드의 **재생**으로 결과를 봅니다. 신들을 선으로 이은 뒤 **플레이그라운드**에서 시퀀스 전체를 재생합니다(`04-sequence-and-playground.md`).

## 5. 알아두면 좋은 것

- **모든 것은 파일입니다.** 신의 내용은 폴더 안 파일이 진실 공급원입니다. 앱 상태(최근 목록·설정·터미널 세션)만 앱 DB에 있습니다.
- **앱이 만드는 파일과 내가 가진 파일이 구분됩니다.** `GUIDE.md`·신 `AGENTS.md`·`prompts/`는 앱이 `scene.json`에서 다시 만드는 생성물입니다(마커 안만 갱신, 밖에 적은 내용은 보존). `src/`·`params/`·`DESIGN.md` 본문은 내 것이라 요청 없이는 덮어쓰지 않습니다.
- **색은 `DESIGN.md` 토큰으로만** 씁니다. 팔레트를 바꾸면 에이전트를 부르지 않고도 느낌이 바뀝니다.
- **정적 페이지는 사용자 입력으로만 넘어갑니다.** 클릭·키·선택지가 있어야 다음 단계/신으로 갑니다.
- 앱은 에이전트를 조종하지 않습니다. 터미널에서 에이전트를 실행하고 프롬프트를 전달할 뿐이며, 에이전트 안의 권한은 해당 CLI가 관리합니다.
