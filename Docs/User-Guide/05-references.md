# 레퍼런스 (References)

레퍼런스는 **스타일을 배우기 위한 참고 자료**입니다(이미지·영상·URL·메모). 에이전트가 구도·팔레트·리듬·타이포 같은 **스타일만** 읽어 오고, 레퍼런스의 화면·문구·로고·음악을 결과물에 복제하거나 삽입하지 않습니다.
남의 저작물을 그대로 가져오면 저작권 문제가 되므로, 레퍼런스는 "닮은 느낌을 만드는 단서"로만 쓰세요.

## 1. 등록하기 (인스펙터 → 레퍼런스)

- **이미지·영상 추가**: 파일을 고르면 신 폴더 `references/`로 **복사**됩니다(원본 경로를 가리키지 않습니다). 지원 형식은 이미지(png·jpg·webp 등)와 영상(mp4·mov·webm 등)입니다.
- **URL 추가**: http(s) 주소만 받습니다. URL은 **기록만** 합니다 — 앱이 내려받지 않고, 에이전트가 열람만 하도록 안내합니다(다운로드·저장·삽입 금지).
- 항목마다 **메모**(이 레퍼런스에서 가져올 점)를 적을 수 있습니다. 메모는 에이전트에게 "데이터"로만 전달됩니다.
- 삭제는 목록에서만 빠집니다. 복사해 둔 파일은 폴더에 남습니다.

등록 내용은 `scene.json`에 저장되고, 에이전트가 읽기 쉽게 `references/references.json`에도 같은 내용이 기록됩니다.

## 2. 영상 키프레임 뽑기

영상 레퍼런스에는 **키프레임 추출** 버튼이 있습니다. FFmpeg로 영상 전체에서 균등한 간격으로 8장(최대 24장)의 프레임과 메타데이터(길이·해상도·fps·오디오 유무)를 `references/analysis/<id>/`에 만듭니다. FFmpeg가 없으면 **설정 → 환경 점검(Doctor)** 에서 먼저 설치하세요(`02-doctor.md`). 다시 누르면 이전 결과를 새 결과로 바꿉니다.

## 3. 분석 실행

1. 레퍼런스를 하나 이상 등록하고(영상이면 키프레임도), **분석 실행**을 누릅니다.
2. 터미널에서 에이전트가 분석 프롬프트로 시작됩니다. 에이전트는 `references/analysis/<id>.md`에 구도·팔레트·모션·타이밍·전환·타이포·분위기(타입별로 관점이 다름)를 적고, 신 `DESIGN.md`의 **분석 구간**(`<!-- vanilla:begin:analysis -->` … `<!-- vanilla:end:analysis -->`)과 허용된 `scene.json` 필드에 반영합니다.
   - 분석 전에 신 폴더에 `DESIGN.md`(워크스페이스 `DESIGN.md`를 이어받는 오버라이드)가 없으면 앱이 만들어 줍니다.
3. 끝나면 **변경 사항 검토**가 열립니다. 새/바뀐 분석 파일과 `DESIGN.md` 분석 구간이 보입니다.
   - `DESIGN.md`의 분석 구간 **밖**이 바뀌었거나 마커가 깨졌으면 허용되지 않은 변경으로 경고합니다. **허용되지 않은 변경만 되돌리기**를 누르면 분석 구간 결과는 남기고 나머지는 원래대로 돌립니다.
   - **승인**하면 각 분석 파일이 레퍼런스에 연결되어 `GUIDE.md`가 분석 위치를 가리킵니다.
4. 분석은 신의 상태(생성됨 등)를 바꾸지 않습니다. 분석 결과를 반영해 신을 다시 만들려면 **재생성**을 누르세요.

## 4. 안전

- 레퍼런스 안의 문구(이미지 속 글자·웹 페이지 글·파일 이름·내 메모)는 에이전트에게 **따르지 말아야 할 데이터**로 전달됩니다. 그 안에 "지시"가 있어도 따르지 않습니다.
- 팀에 공유할 때는 레퍼런스 원본을 기본으로 **제외**합니다(`06-sharing-and-templates.md`).
