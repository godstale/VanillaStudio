# 신과 가이드 (Scenes & Guides)

신(Scene)은 화면 하나의 단위입니다. 타입은 셋입니다.

| 타입 | 용도 | 움직임 |
| --- | --- | --- |
| **정적 페이지**(`static`) | 웹 페이지·슬라이드 | 시간이 아니라 스크롤·입력. `scroll`(긴 페이지) 또는 `steps`(슬라이드형, 클릭·키·선택지로 단계 이동) |
| **모션 그래픽**(`motion`) | 광고·소개 영상 같은 시간 기반 화면 | 시간 `t`의 순수 함수(같은 `t` → 같은 프레임) |
| **3D 애니메이션**(`3d`) | three.js 장면 | 모션과 같은 시간 계약 |

## 1. 신 만들기

캔버스에서 **신 추가**(또는 빈 곳 오른쪽 클릭) → 이름·타입·템플릿을 고릅니다. 템플릿은 내장 3종과 내가 만든 신 템플릿(`06-sharing-and-templates.md`)이 나옵니다.
만들어지는 폴더:

```
scenes/<이름>/
├─ scene.json     # 구조화된 신 설명(앱이 정규 형식으로 저장)
├─ GUIDE.md       # 사람용 요약(앱이 생성, 읽기 전용)
├─ AGENTS.md      # 에이전트용 지침(앱이 생성)
├─ CLAUDE.md      # AGENTS.md를 읽게 하는 한 줄
├─ prompts/       # generate · revise · analyze-reference · user-prompt
├─ src/           # 에이전트가 만드는 코드(내 파일)
├─ params/        # 사용자가 조절한 값(내 파일)
└─ references/    # 레퍼런스와 분석 결과
```

## 2. 인스펙터

노드를 고르면 오른쪽에 탭이 열립니다.

- **개요**: 이름·타입·템플릿, 브리프(주제·목적·대상·핵심 메시지·언어), 시작 신 지정, 신 템플릿으로 저장.
- **가이드**: 타입별 폼. 용어는 드롭다운에서 고르거나(저장은 용어 ID) 자유 입력도 됩니다. 모션·3D는 **beats**(시간 구간별 역할·카피·모션·카메라·전환)를 편집하고 시간 합이 길이와 맞는지 표시합니다. 정적 페이지는 **steps**(단계별 입력)를 편집합니다.
- **디자인**: `DESIGN.md` 토큰 요약·팔레트 적용·분위기 키워드·신 오버라이드.
- **레퍼런스**: `05-references.md`.
- **프롬프트**: 에이전트에게 보낼 프롬프트 미리보기(클립보드로 복사되는 것과 같은 내용)와 내 프롬프트 편집.
- **미리보기**: 신 하나를 재생합니다. 재생·일시정지·시크(모션·3D), 단계 이동(정적), **계약 검사**.

폼을 고치면 잠시 뒤 `scene.json`이 저장되고 `GUIDE.md`·`AGENTS.md`·`prompts/`가 다시 만들어집니다.
저장할 수 없는 값(예: 시간 구간이 이어지지 않음)은 파일에 쓰지 않고 이유를 보여 줍니다.

## 3. 에이전트 실행

1. 노드의 **에이전트 실행**을 누릅니다. 이 신의 폴더에서 터미널이 열리고(기본 에이전트 또는 설정에서 켠 에이전트), 프롬프트가 **클립보드에 복사**됩니다. 자동 붙여넣기를 켜 두었다면 에이전트가 준비된 뒤 붙여 넣습니다.
2. 에이전트가 `src/`를 만들고 허용된 필드(`scene.json`의 구조·스타일 필드)를 채웁니다. 에이전트가 **고칠 수 없는 필드**(이름·브리프·내 프롬프트·레퍼런스·카피 등)는 `AGENTS.md`에 적혀 있습니다.
3. 에이전트가 끝나면 앱이 `scene.json`을 다시 검증하고 **변경 사항**을 보여 줍니다.
   - 허용된 필드의 변경만 있으면 **승인**하면 됩니다. 신 상태가 `생성됨`이 됩니다(`src/index.html`이 있어야 합니다).
   - 허용되지 않은 필드가 바뀌었으면 경고가 뜹니다. **허용되지 않은 변경만 되돌리기** 또는 **전부 되돌리기**를 고르세요.
   - 에이전트가 신 폴더 **밖**에 쓴 파일이 있으면 캔버스에 경고가 뜹니다.
4. 되돌리기를 대비해 실행 전·승인 후 상태가 `scenes/<이름>/.vanilla/history/`에 남습니다.

## 4. 고치고 다시 만들기

폼이나 내 프롬프트를 고치면 신 상태가 `수정 필요`가 되고 노드 버튼이 **재생성**으로 바뀝니다. 재생성 프롬프트에는 **마지막으로 확정한 상태 이후 바뀐 필드**가 함께 들어갑니다.

## 5. 계약 검사

**미리보기 → 계약 검사** 또는 신 폴더가 있는 워크스페이스에서 `pnpm check:scene [신 이름]`을 실행하면 다음을 검사하고 `.vanilla/self-check.md`에 씁니다.

- 모션·3D: 금지된 시간 API(`Date.now`·`performance.now`·`Math.random`·직접 `requestAnimationFrame`·`setInterval`), `defineScene` 기본 내보내기, beats 시간 구간·엔드 카드(0.7초 이상), 카피 원문(`exact`)이 코드에 그대로 있는지
- 모두: 하드코딩된 색(경고)

오류가 있으면 에이전트에게 고쳐 달라고 요청하세요. 같은 시간에 같은 프레임이 나와야 시퀀스 재생·공유가 안정적입니다.

## 6. 파일 소유와 안전

- 앱이 다시 만드는 생성물은 `<!-- vanilla:begin:… -->` 마커 안만 갱신합니다. 마커 밖에 직접 적은 내용은 보존됩니다.
- `GUIDE.md`를 직접 고치면 앱이 "수동 편집 감지"로 알려 줍니다. 고치려면 인스펙터에서 하세요.
- 에이전트는 신 폴더 안에서만 일하도록 되어 있습니다. 앱은 에이전트의 셸·네트워크 권한을 대신 결정하지 않습니다(해당 CLI의 권한 설정을 따름).
