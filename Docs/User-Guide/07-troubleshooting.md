# 문제 해결 (Troubleshooting)

먼저 **설정 → 환경 점검(Doctor)** 에서 Node·pnpm·에이전트 CLI·FFmpeg 상태를 확인하세요(`02-doctor.md`).

## 에이전트·터미널

| 증상 | 확인할 것 |
| --- | --- |
| **에이전트 실행**을 눌러도 터미널이 열리지 않음 | 폴더를 신뢰했는지(처음 여는 폴더는 신뢰 확인이 뜹니다) → 설정에서 켠 에이전트가 있는지("사용할 수 있는 에이전트가 없습니다" 안내) → Doctor에서 해당 CLI가 설치됐는지 |
| 에이전트 CLI가 설치되어 있지 않다고 나옴 | Doctor의 설치 안내를 따르세요. 다른 에이전트를 기본으로 바꿔도 됩니다(설정) |
| 프롬프트가 붙여넣어지지 않음 | 클립보드에는 이미 복사되어 있으니 터미널에서 직접 붙여넣으세요(자동 붙여넣기는 에이전트가 준비된 것을 알아챈 경우에만 동작) |
| 에이전트가 끝났는데 변경 사항 창이 안 뜸 | 앱이 실행한 터미널에서 끝난 경우에만 검토가 열립니다. 신을 다시 선택하면 최신 상태를 읽습니다 |
| "신 폴더 밖의 파일을 바꿨습니다" 경고 | 에이전트가 이 신 밖(다른 신·워크스페이스 파일)에 썼습니다. 내용을 확인하고 필요하면 되돌리세요 |

## 미리보기·플레이그라운드

| 증상 | 확인할 것 |
| --- | --- |
| 미리보기가 "서버를 시작하지 못했습니다" | 의존성 설치 여부(워크스페이스의 `node_modules`) → **다시 시도**. 설치가 안 되어 있으면 워크스페이스 폴더에서 `pnpm install` |
| 미리보기는 열리는데 화면이 비어 있음 | 신에 `src/index.html`이 있는지, 계약 검사에서 `defineScene` 오류가 없는지(`03-scenes-and-guides.md` §5) |
| 플레이그라운드가 "고쳐야 할 문제"를 보여 줌 | 시퀀스 검사 오류입니다(`04-sequence-and-playground.md` §4). 캔버스에서 해당 연결을 고치세요 |
| 신을 불러오지 못해 멈춤 | 신 코드의 오류일 수 있습니다. 오류 배너의 내용을 에이전트에게 전달하고 **다시 시도** |
| 정적 페이지에서 클릭해도 다음 신으로 안 감 | 마지막 단계에서만 선을 따라갑니다. 그 신에서 나가는 선의 조건이 클릭·키·선택지인지 확인 |
| 같은 시각인데 모양이 다름 | 모션·3D 신이 `Date`·`Math.random`·자체 타이머를 쓰고 있을 수 있습니다. 계약 검사를 실행하세요 |

## 레퍼런스

| 증상 | 확인할 것 |
| --- | --- |
| 키프레임 추출이 "FFmpeg가 설치되어 있지 않습니다" | Doctor에서 FFmpeg를 내려받으세요 |
| "영상 스트림이 없는 파일입니다" | 오디오만 있는 파일이거나 손상된 파일입니다 |
| URL 레퍼런스를 앱이 열어 보지 않음 | 의도된 동작입니다. 앱은 URL을 내려받지 않고 기록만 합니다 |

## 패키지·가져오기

| 증상 | 확인할 것 |
| --- | --- |
| 패키지를 열 때 "체크섬이 맞지 않습니다" | 전송 중 손상되었거나 수정된 파일입니다. 다시 받으세요 |
| "안전하지 않은 경로나 링크" | 악의적이거나 손상된 패키지일 수 있어 거부했습니다. 출처를 확인하세요 |
| "더 새롭거나 호환되지 않는 버전" | 앱을 업데이트하거나, 보낸 사람에게 호환 버전으로 내보내 달라고 하세요 |
| 가져온 신의 가이드 파일이 없음 | 그 신이 쓰는 템플릿이 이 워크스페이스에 없습니다. 템플릿을 설치(설정 → 가이드 템플릿)한 뒤 신을 한 번 저장하세요 |
| 같은 이름의 템플릿이 있어 가져오지 않음 | 의도된 동작입니다(기존 템플릿을 덮어쓰지 않습니다) |

## 파일·데이터

- **`GUIDE.md`·`AGENTS.md`를 직접 고쳤더니 사라졌어요**: 마커(`<!-- vanilla:begin:… -->`) **안**은 앱이 다시 만듭니다. 내 메모는 마커 **밖**에 적으세요.
- **`scene.json`을 직접 고쳤더니 오류**: 형식이 어긋나면 노드에 오류 표시가 뜹니다. 인스펙터에서 고치는 것이 안전합니다.
- **폴더를 옮기거나 다른 PC로 가져가고 싶어요**: 폴더째 복사해도 되고, `.vsx`로 공유해도 됩니다. 앱이 만드는 파일은 환경에 의존하지 않습니다(`Docs/Verification/Reproducibility.md`).

문제가 해결되지 않으면 `scenes/<이름>/.vanilla/self-check.md`(계약 검사 결과)와 터미널 출력을 함께 정리해 두세요.
