# 03. 비주얼 디렉션 (Visual Direction)

> 색·타이포·분위기는 `DESIGN.md` 토큰이 책임집니다. 여기에는 "왜 이렇게 보이는가"만 적습니다.

## 분위기

(예: 짙은 네이비 무대 위에 앰버 한 가지 강조색의 키노트)

## 공통 (Invariant)

- 네이비 그라디언트 배경 + 은은한 따뜻한/차가운 빛
- 좌상단 앰버 세로바 + 신 제목, 우상단 챕터 칩
- 슬레이트 카드, 흰 바탕 도식은 `paper` 액자

## 가변 (Variant)

- 화면마다 레이아웃(`cover`, `statement`, `cards`, …)
- 사진·도식, 강조 단어(`**단어**`), 연도(`year`)

## 바꾸고 싶다면

색은 `DESIGN.md` front matter의 `colors`만 바꿉니다. 코드에 hex 값을 직접 쓰지 않습니다.
