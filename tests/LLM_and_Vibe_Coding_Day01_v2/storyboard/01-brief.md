# 01 — 기획서 (Brief)

## 타이틀

언어모델(LLM)과 AI 산업의 이해 — 1일차 (수정 강의안판)

## 핵심 한 문장

알파고가 보여 준 "먼저 온 미래"에서 출발해 1943년 인공 뉴런부터 2026년 프런티어 모델까지의 연대기를 따라가며, 다가올 미래를 준비하는 첫걸음으로 신경망과 언어모델을 이해한다.

## 목적

- 2026-10-24(토) 1일차 강의를 `references/수정-강의안.txt`의 흐름 그대로 진행할 발표 화면을 만든다.
- 강의안 Scene 1개 = Vanilla 신 1개. 내용이 많은 Scene은 신 안에서 여러 화면(step)으로 나눈다.
- 강연자가 말로 풀고, 화면은 핵심어·연도·사진·도식만 크게 보여 준다.

## 다룰 내용 (In-Scope)

- 본편 Scene 1~22: 알파고 쇼크 → 프로그래밍 업계 → 다가올 미래 → 뇌·뉴런 → 퍼셉트론 → 역전파·겨울 → 손글씨·CNN·RNN → 딥 블루 → 부활 → AlexNet → Word2Vec·Seq2Seq·Attention → GAN → ResNet → 딥마인드·알파고 → Transformer → OpenAI·GPT → 스케일링·알파폴드·확산 모델 → RLHF·ChatGPT·2023/2024 → 2025/2026 → 네팔의 짐꾼
- 보너스 E1~E6(시간이 남을 때): 문장 이해 3단계, 임베딩(스무고개), 어텐션·FFN·레이어, 프리필·디코딩, 숫자로 보는 LLM, GPU·메모리 병목
- 강의자가 준비한 이미지 31장(`assets/img/`)

## 하지 않을 것 (Non-Goals)

- 대본 전체를 화면에 옮기기, 자동 넘김, 반복 애니메이션
- 생성형 이미지 AI로 그림 만들기(D-006) — 필요한 도식은 코드(SVG)로 그린다
- 기존 Day01 덱(`../LLM_and_Vibe_Coding_Day01`) 수정 — 비교·백업용으로 그대로 둔다
