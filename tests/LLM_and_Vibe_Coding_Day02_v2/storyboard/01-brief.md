# 01 — 기획서 (Brief)

## 타이틀

LLM과 바이브 코딩 — 2일차 (수정 강의안판)

## 핵심 한 문장

ChatGPT 쇼크에서 출발해 Copilot·Cursor·Claude Code를 거쳐 에이전트를 다루는 방법론(Plan·Skill·서브 에이전트·루프·하네스)이 진화하는 과정을 따라가고, 특이점에 다가선 2026년 에이전트의 성과와 위험을 함께 본다.

## 목적

- 2일차 강의를 `references/수정-강의안-Day02.txt`의 흐름 그대로 진행할 발표 화면을 만든다.
- 1일차 덱(`../LLM_and_Vibe_Coding_Day01_v2`)과 **같은 형식·템플릿**: 강의안 Scene 1개 = Vanilla 신 1개, 내용이 많은 Scene은 신 안에서 여러 화면(step)으로 나눈다.
- 강연자가 말로 풀고, 화면은 핵심어·연도·사진·도식만 크게 보여 준다.

## 다룰 내용 (In-Scope)

- 바이브 코딩의 시작까지(S1~S5): GPT 쇼크 → 프로그래머들의 탐색 → GitHub Copilot → 탭 코딩 → Cursor와 코딩 에이전트
- 진화사 01 · LLM을 에이전트로(S7~S10): 걸음마(프롬프트·기억) → 도구를 쥔 AI(ReAct) → MCP → Claude Code
- 진화사 02 · 에이전트의 날갯짓(S11~S18): Plan 모드 → Thinking Effort → Skill → 서브 에이전트 → 루프 엔지니어링 → SDD·TDD → 독립형 에이전트(OpenClaw) → 하네스 엔지니어링
- 진화사 03 · 특이점(S19~S22): LLM 가속·RSI → 탈옥 → 비상(Astra·Opus 5.5·상시 비서) → 성과(수학·과학·법률·창작·보안·게임·Physical AI)
- 맺음말(S23): AI 사용 피라미드와 질문
- 강의자가 준비한 이미지 15장(`assets/img/`)

## 하지 않을 것 (Non-Goals)

- 대본 전체를 화면에 옮기기, 자동 넘김, 반복 애니메이션
- 생성형 이미지 AI로 그림 만들기(D-006) — 필요한 도식은 코드로 그린다
- 1일차 덱 수정 — 같은 템플릿을 복사해 이 워크스페이스에서만 고친다
- 강의안에 없는 사실·수치 추가(아래 표기법 정리 제외)

## 강의안 대비 수정 사항

원문은 `references/수정-강의안-Day02.txt`. 사실 관계는 바꾸지 않고 표기만 정리했다. 되돌리려면 `storyboard/data/content.json`만 고친다.

| Scene | 원문 | 반영 |
| --- | --- | --- |
| 걸음마 | 대화 내역 기억 = 챗 기록을 덧붙여 보냄 “(System prompt 영역)” | “시스템 프롬프트와 지난 대화 기록을 덧붙여 보내기 때문” — 대화 기록은 시스템 프롬프트와 별개의 메시지 영역이라 함께 적음 |
| GitHub Copilot | 3위 일체 | 삼위일체 |
| 오타 | 날개짓, 많이짐, 강회된, 줄어듬, 물 밑, 허사비스 | 날갯짓, 많아짐, 강화된, 줄어듦, 물밑, 하사비스(1일차 표기) |

강의안에 연도가 있는 화면만 하단 연대기 바(2021→2026, 월 단위)를 표시한다. 개념 화면(Plan·Effort·Skill·서브 에이전트·루프·SDD/TDD·하네스)은 연도를 보충하지 않았다.
