# 03 — 비주얼 디렉션 (Visual Direction)

## 무드

1일차와 같다: 짙은 네이비 무대, 앰버 한 가지 강조, 굵은 한글 제목. 차분하고 신뢰감 있는 키노트.
2일차는 도구·방법론 이야기가 많아 사진보다 **코드로 그린 개념 도식**의 비중이 크다.

## 불변 요소 (A — 모든 화면 공통, 1일차와 동일)

- 배경: 네이비 그라디언트 + 우상단 따뜻한 빛 + 좌하단 푸른 빛
- 좌상단: 앰버 세로바 + 제목(52px) + 부제 / 우상단: 챕터 칩 `[번호] 챕터명` / 우하단: 신 번호·화면 점
- 연도가 있는 화면: 하단 2021→2026 연대기 바(월 단위), 현재 시점 앰버 점·라벨
- 카드: 반투명 슬레이트 + 1px 테두리 + 둥근 모서리 / 흰 바탕 도식은 밝은 종이 액자
- 강조: `**단어**`만 앰버. 움직임: 화면 전환 페이드·살짝 올라오기, 순차 항목 페이드

## 가변 요소 (B — 화면마다)

- 레이아웃 14종(content.json `layout`), 사진/도식, 강조 단어, 연도
- 진화사 3단계(02·03·04 챕터)는 구분 화면(큰 앰버 번호 + 제목)으로 시작
- 탭 코딩: 에디터 창 도식에서 주석 타이핑 → 회색 제안 → Tab 수락(클릭 3번)
- 맺음말: 사용 피라미드를 아래에서 위로 한 층씩, 마지막은 한 문장 질문
